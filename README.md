# InAmigos Foundation - NGO Awareness Webpage

This is a simple awareness webpage created for the InAmigos Foundation as part of my internship task.

The main idea behind this project is to introduce the foundation, show the different initiatives it works on, highlight its impact, and encourage people to get involved.

## What the Website Includes

- A landing section introducing InAmigos Foundation
- About section with information about the foundation
- Six project/initiative cards
- Impact statistics
- Ways people can contribute
- Links to the official website and LinkedIn page
- Responsive design for different screen sizes

## Projects

The webpage covers these initiatives:

- **Bachpanshala** - Education
- **Udaan** - Women Empowerment
- **Jeev** - Animal Welfare
- **Seva** - Community Support
- **Prakriti** - Environment
- **Vikas** - Skill Development

## Technologies Used

- HTML
- CSS
- Google Fonts
- Font Awesome
